本地换图 · 最简说明

图片在 public/content/，不绑 webpack 文件名。换图多数情况不用改代码。

相册

  1. 照片放进 public/content/gallery/（文件名随意）
  2. 运行 npm run sync-content（npm start 会自动跑）
  3. git push origin master

首页轮播

覆盖固定文件即可：

文件说明
banner/slide-1.jpg第 1 张
banner/slide-2.jpg第 2 张
… slide-3 ~ 5第 3–5 张

改标题：编辑 banner/slides.json 里的 alt。

换届 · 加新人

  1. 照片放进 public/content/members/zhangsan.jpg
  2. 编辑 public/content/teams.json，在 boardTeam 等数组里加一条（可复制文件里的 _memberTemplate）
  3. git push origin master

离任：从 teams.json 删掉对应条目。换头像：覆盖同名 jpg，不用改 JSON。

成员头像（已在 teams.json 里的人）

覆盖 public/content/members/ 里固定名，例如 helen.jpg、tim.jpg。

本地开发

npm install
npm start          # localhost:3000
npm run upload     # 可选：本地上传页 localhost:3333
部署：push 到 master → 等 GitHub Actions → 硬刷新网站。
